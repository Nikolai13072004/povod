# Roadmap POVOD

Документ синхронизируется с парным репозиторием POVOD. Приоритеты могут меняться, но завершённые пункты не удаляются: они переносятся в `CHANGELOG.md`.

## Цель

Довести POVOD до самостоятельного, публично демонстрируемого pet-проекта: его можно клонировать, запустить локально и использовать для полного сценария работы с событиями.

## Ближайший этап — стабильный MVP

- [ ] Единый локальный запуск frontend, backend и PostgreSQL через Docker Compose.
- [ ] Актуальный README без привязки к хакатонной инфраструктуре.
- [ ] Единая конфигурация окружения и проверка API-контракта.
- [ ] Обработка состояний загрузки, ошибок и пустых списков.

## Следующий этап — надёжная модель данных

- [ ] Нормализованные таблицы пользователей, событий, участников, комментариев и дружб.
- [ ] Миграции базы данных и тестовые данные.
- [ ] Серверная аутентификация и проверка прав автора события.
- [ ] ISO-даты в API и локализованное форматирование в интерфейсе.

## Продуктовые функции

- [ ] Раздел «Мои события» из данных сервера: созданные и посещаемые.
- [ ] Избранное, лимит участников и приватные события по приглашению.
- [ ] Рекомендации по интересам, городу и друзьям.
- [ ] Настоящие уведомления о приглашениях и изменениях события.
- [ ] Загрузка и оптимизация изображений событий.

## Качество и портфолио

- [ ] Unit/API/E2E-тесты и линтер.
- [ ] GitHub Actions для проверок и сборки.
- [ ] Публичный deploy с безопасными переменными окружения.
- [ ] Скриншоты, короткое демо и понятный README для GitHub-профиля.
- [ ] Решение о переходе в monorepo только после стабилизации API и локального запуска.
