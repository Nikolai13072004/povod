# Журнал изменений POVOD

Этот файл синхронизируется с `CHANGELOG.md` в парном репозитории POVOD. Он хранит историю значимых изменений всего продукта, а не только одной части приложения.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Используем разделы `Добавлено`, `Изменено`, `Исправлено`, `Безопасность` и `Документация`.

## [Не выпущено]

### Изменено

- Архитектурное направление: POVOD развивается как самостоятельное web/PWA-приложение с независимыми адаптерами для VK, Telegram, MAX и других платформ, а не как приложение одной экосистемы.
- Добавлена конфигурация единого локального запуска через Docker Compose: frontend, backend и PostgreSQL.
- Исправлен Docker healthcheck backend: он использует IPv4 loopback и корректно работает в Alpine-контейнере.

### Документация

- Созданы единый журнал изменений, описание архитектуры, roadmap и правила совместной работы для frontend и backend, включая инструкции для AI-агентов.

## [0.1.0] — 2026-07-22

### Добавлено

- Базовый full-stack MVP: React/Vite/VKUI frontend и Express/TypeScript backend.
- Лента, фильтрация, создание и просмотр событий, запись на событие и комментарии.
- Интеграции VK Bridge, VK launch-параметров и KudaGo.
- Режимы хранения in-memory, JSON-файл и PostgreSQL JSONB-снимок.
- Dockerfile для обеих частей приложения.

### Проверено

- Backend проходит `npm run typecheck`.
- Frontend проходит production-сборку `npm run build`.

### Примечания

- Frontend и backend находятся в одном monorepo и образуют один продукт.
- Любое изменение API-контракта, архитектуры или заметной функции должно быть отражено в обоих `CHANGELOG.md`.
