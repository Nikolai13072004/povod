# Скриншоты для README

Сюда кладутся кадры, которые показываются в корневом `README.md`.

## Что снять

| Файл | Экран | Как получить |
| --- | --- | --- |
| `feed.png` | Лента событий с фильтрами | `/page-1` после входа |
| `event.png` | Карточка события | клик по любому событию |
| `create.png` | Форма создания повода | кнопка «+» в нижней навигации |
| `my-events.png` | «Мои события» с вкладками | третья вкладка внизу |

## Как снимать

1. Запустите приложение: `docker compose up --build`.
2. Войдите демо-аккаунтом `elmira@povod.app` / `povod-demo`.
3. Ширина окна — **1280 px** (десктоп) или **390 px** (мобильный вид); в пределах
   одного набора не смешивайте.
4. Формат — PNG. Желательно сжать (например, [squoosh.app](https://squoosh.app)),
   чтобы каждый файл был меньше ~300 KB: репозиторий уже чистили от тяжёлых картинок.

## После добавления

Раскомментируйте блок со скриншотами в корневом `README.md` — таблица уже готова и
ссылается на эти имена файлов.
